# 好买网退货政策

## 退货时限
- 自签收之日起 **15 天**内可申请无理由退货
- 生鲜食品、定制商品不支持无理由退货
- 超过 15 天但不超过 30 天，仅限质量问题退货

## 退货条件
- 商品需保持原包装完好，不影响二次销售
- 需提供购买凭证（订单号即可）
- 赠品需一并退回

## 退货流程
1. 在"我的订单"中找到对应订单，点击"申请退货"
2. 选择退货原因，上传商品照片
3. 系统审核通过后，会生成退货快递单
4. 将商品寄回指定地址（运费由好买网承担）
5. 仓库收到商品并验收后，3 个工作日内退款

## 退款方式
- 原路退回：退回到支付时使用的账户
- 退款到好买网余额：即时到账
- 银行卡退款：1-5 个工作日到账
