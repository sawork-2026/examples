# 好买网物流配送

## 配送范围
- 支持中国大陆所有省市区（港澳台暂不支持）
- 偏远地区（新疆、西藏、青海部分区域）配送时效可能延长

## 配送时效
- 同城：下单后 **当日达** 或 **次日达**（截止时间 14:00）
- 省内：**1-2 个工作日**
- 跨省：**2-5 个工作日**
- 偏远地区：**5-7 个工作日**

## 运费标准
- 订单满 **99 元**包邮
- 未满 99 元，收取 8 元运费
- 大件商品（冰箱、洗衣机等）单独计费，详见商品页面
- 会员用户享受免运费权益（详见会员政策）

## 物流查询
- 在"我的订单"中查看物流状态
- 支持顺丰、京东物流、圆通、中通等主流快递
- 可通过快递单号在对应快递官网查询实时位置
